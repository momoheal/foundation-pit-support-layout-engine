# 基坑内支撑生成几何约束设计

## 目标

把内支撑生成器的几何规则从“画线逻辑”提升为“工程拓扑逻辑”。程序生成的每一根腰梁、对撑、角撑、边桁架弦杆、腹杆、连杆和立柱，都必须对应真实基坑支撑体系中可解释、可连接、可检查的构件。

本文先约束平面几何与节点拓扑，不替代结构计算、稳定验算、截面设计、预加力设计或施工方案审查。

## 依据

- 《建筑基坑支护技术规程》JGJ 120-2012，第 4.9 节“内支撑结构”：规定内支撑体系组成、平面布置、阳角斜撑、腰梁/冠梁连接、支撑点间距、八字斜撑、立柱布置等要求。参考 PDF: [JGJ 120-2012](https://www.bjhcgk.com/upload/files/20230113/JKMSUYUY-20230113100648.pdf)。
- 工程资料对 JGJ 120-2012 第 4.9.11 的解释也明确：形状不规则基坑可采用正交/斜交杆系、边桁架或桁架对撑；支撑应避开主体墙柱；相邻支撑水平间距宜满足挖土机械空间；水平支撑应通过腰梁或冠梁连接挡土构件。参考：[内支撑结构设计10项内容介绍](https://www.geoseu.cn/yanjiuyuan/neizhicheng_jiegou_sheji_10_neirong_jieshao.html)。

## 核心几何原则

1. 先建立主受力拓扑，再生成桁架细部。生成顺序应是：waling -> 多道角撑 -> 各边对撑 -> 边桁架弦杆 -> 边桁架腹杆 -> 角撑层间连杆 -> 对撑连杆 -> 立柱 -> 全局几何检查。
2. 所有成员端点必须锚固到真实对象：腰梁/冠梁、已有构件节点、桁架节点、环梁节点或立柱节点。不得把质心、边中点、投影点直接当成悬空端点。
3. 所有非端点交叉必须被分类：设计交汇点写入 `nodes`；非设计交叉视为错误；允许的单纯跨越必须有明确规则和构造解释。
4. 构件必须位于 waling 内有效支撑域内。任何外伸、穿越空洞、穿入核心保护区或穿越无支撑区域的线段都应裁剪或拒绝。
5. 平行或近似平行的重复杆件不能靠很近并同时输出。重复杆、重叠杆和无效短杆应在输出前消除。

## 角撑几何定义

角撑不是从角点向基坑内部发散的径向线。正确的平面几何应以阳角相邻两侧腰梁为两边，沿两侧腰梁分别取点，再用一根斜线连接这两个取点，形成贴近角部的三角形支撑线。

多道角撑应是多条嵌套的三角形线：

- 对每个凸角，沿前一条腰梁边取 `left_i`，沿后一条腰梁边取 `right_i`。
- 第 `i` 道角撑为 `left_i -> right_i` 的斜撑。
- `left_i/right_i` 必须落在对应腰梁边上，不能落在质心射线、角平分线或任意内部点上。
- 多道角撑之间的连杆应沿两侧腰梁方向连接 `left_i -> left_{i+1}` 与 `right_i -> right_{i+1}`，形成可解释的角部支撑带。
- 只对凸角生成角撑。凹角不得按阳角角撑逻辑生成跨空斜杆。

## 对撑与边桁架关系

对撑应先于边桁架细化生成。边桁架不是独立装饰线，而是服务于已确定的主支撑拓扑。

- 对撑端点应落到 waling，并登记为边界锚点。
- 边桁架外弦杆沿 waling 方向布置，内弦杆按桁架深度向坑内偏移。
- 边桁架面板节点必须强制吸附以下点：对撑端点、角撑端点、角撑连杆端点、已有边界支撑节点。
- 腹杆生成前必须检查与对撑、角撑、连杆的交叉。若腹杆穿越主支撑而交点不是设计节点，应拆分面板、跳过该腹杆或切换腹杆型式。
- 不允许出现对撑端点和边桁架弦杆端点在几何上很近但属于不同节点的情况。

## 规范约束转程序规则

### 支撑平面布置

- 内支撑布置应满足主体结构施工要求，并尽量避开地下主体结构墙、柱。当前参数没有主体墙柱输入时，程序只能保留接口和文档约束，不能伪造避让。
- 机械挖土工况下，相邻支撑水平间距不宜小于 4m。程序应对小于该阈值的主支撑间距给出 warning 或拒绝，具体策略由后续实现计划确定。
- 基坑有阳角时，阳角处斜撑应在两边同时设置。程序规则对应为“两侧腰梁取点成三角形线”，不是单侧线或径向线。
- 水平支撑必须通过腰梁或冠梁与挡土构件连接。程序规则对应为：主对撑、八字撑、角撑、边桁架外弦杆端点必须锚固到 waling 或 waling 上的显式节点。
- 腰梁/冠梁上的支撑点间距：钢腰梁不宜大于 4m，混凝土腰梁不宜大于 9m。当前生成器可先按 `strut_material` 或未来 `waling_material` 区分 warning 阈值。

### 八字斜撑

八字斜撑不是普通角撑。它用于主撑端部两侧，当相邻水平支撑间距较大时辅助腰梁受力。

- 八字斜撑应在主撑端部两侧对称布置。
- 八字斜撑端点应连接主撑端节点与腰梁/冠梁节点。
- 八字斜撑长度不宜大于 9m。
- 八字斜撑与腰梁/冠梁夹角宜为 45° 到 60°。
- 程序不得把八字斜撑与阳角多道角撑混为一种构件。

### 环形支撑

- 环梁宜采用圆形、椭圆形等封闭曲线形式。
- 辐射支撑应连接环梁与腰梁/冠梁，不得从质心直接发散到任意边界点。
- 环形支撑应与腰梁或冠梁形成交汇布置，环梁节点和径向支撑端点都必须进入节点模型。

### 立柱

- 纵横双向交叉支撑结构中，立柱宜设置在支撑交汇点处。
- 立柱不得布置在每一个桁架节点上；应从主撑交汇、主撑-连杆交汇、必要长跨支承点中筛选。
- 立柱与支撑端部及立柱之间的间距应受稳定和竖向荷载控制。仅做几何生成时，应保留最大间距 warning，不把它当作结构验算结论。

### 连接与斜交

- 水平支撑与腰梁斜交时，真实工程中需要牛腿或其他抗剪连接措施。程序层面的几何规则是：斜交端点必须识别为特殊连接节点，不能与普通正交节点等同。
- 所有连接节点应携带来源成员 id，便于 DXF、诊断图和验证器追踪。

## 推荐生成顺序

1. 生成 waling，并保存每条边、每个顶点、凸凹角分类。
2. 对凸角生成多道角撑：沿两侧腰梁取点，连接成三角形线。
3. 按边和方向生成主对撑，端点锚固到 waling；主撑交叉点写入 `nodes`。
4. 汇总边界锚点：对撑端点、角撑端点、角撑连杆端点、既有 waling 节点。
5. 生成边桁架外/内弦杆，面板节点吸附边界锚点。
6. 生成腹杆；每根腹杆先经过交叉检查、最小长度检查、平行重复检查，再加入模型。
7. 生成多道角撑之间的连杆。
8. 生成对撑之间的 ties。
9. 从真实结构节点筛选立柱。
10. 执行全局检查：端点锚固、非法交叉、近距平行、重复杆、悬空节点、过密支撑点、waling 支撑点超限。

## 验证器应新增或强化的检查

- `corner_brace_not_radial`: 角撑两端必须分别落在相邻两条腰梁边上。
- `convex_corner_only`: 只有凸角允许生成阳角角撑。
- `edge_truss_snaps_to_primary_anchors`: 边桁架节点必须吸附主撑/角撑端点。
- `web_does_not_cross_primary_support`: 腹杆不得无节点穿越主撑、角撑、连杆。
- `no_duplicate_nearby_nodes`: 距离小于容差的结构节点必须合并或共享。
- `waling_support_spacing_limit`: 腰梁/冠梁上的支撑点间距超过材料阈值时报告 warning。
- `brace_angle_length_rule`: 八字斜撑检查 45° 到 60°夹角和 9m 长度建议值。
- `pillar_from_structural_nodes_only`: 立柱只能来自主结构交汇或稳定需要的支承点。

## 非目标

- 不在本规则里做截面、配筋、长细比、承载力、预加力或施工阶段验算。
- 不凭几何规则判断方案安全，只判断生成几何是否像真实工程构造。
- 不新增与当前体系无关的支撑类型。
