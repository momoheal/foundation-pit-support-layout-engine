3. Add a private helper named `_large_brace_corner_anchor_model(...)`.
4. Have the helper return:

   ```python

   ```

5. In the helper, generate anchors only for convex waling corners.
6. For each convex corner, take points along the two adjacent waling edges and connect them as triangular corner semantic lines.
7. Add same-side layer semantic lines between consecutive anchor layers.
8. Use existing spacing parameters only: `spacing`, `spacing_min`, `truss_panel_max`, and `corner_layers`.
9. Do not output these semantic lines as layout members.
10. Extend `_place_edge_truss()` with keyword-only optional parameters:

    ```python

    avoid_lines=None
    ```

11. Keep existing `_place_edge_truss()` callers compatible.
12. Merge edge truss outer chord nodes from:

    ```text
    existing panel nodes

    ```

13. Before adding each `truss_web`, reject it if it creates a non-endpoint crossing with:

    ```text

    ```

14. Update the large rectangle `brace` branch to:

    ```python

    self._place_edge_truss(
        layout,
        waling_poly,
    ```
